# BL2 Combined

A customizable compilation of **Many QoL mods**, with additional settings for the reward chests in Haderax’s arena and Digistruct Peak.

## Installation

1. Use a PC installation of Borderlands 2 already configured for text mods. See the [community guide to enabling the console](https://github.com/BLCM/BLCMods/wiki/Tutorial%3A-Enabling-Console).
2. Copy `BL2Qol.txt` into `Borderlands 2/Binaries`.
3. At the main menu, before loading a character, open the console and enter:

```text
exec BL2Qol.txt
```

## Customizing the mods in OpenBLCMM

In [OpenBLCMM](https://github.com/BLCM/OpenBLCMM), choose **File → Open** and select `BL2Qol.txt` to customize the settings to your liking.
